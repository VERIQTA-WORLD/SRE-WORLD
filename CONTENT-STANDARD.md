# SRE content standard

Connect each concept to a service, user outcome or operational decision. Explain assumptions, dependencies and trade-offs. Distinguish availability, reliability and durability rather than using them interchangeably.

Measurement examples state the indicator definition, numerator, denominator, time window, target and exclusions. Calculations must be reproducible. Alert examples explain the intended response and verification.

Labs require isolated setup, expected results, troubleshooting and cleanup. Projects require reproducible deployment, independent work, measured behaviour and tested recovery.

Incident material separates evidence, hypotheses and conclusions. Public cases require source attribution; original practice scenarios must be identified as such. Avoid unsupported causal claims and invented improvement statistics.
